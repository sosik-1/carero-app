# 케어로 시연 가이드 (Windows)

Pleos Connect Emulator에서 앱을 실행하고 시연 영상을 녹화하는 순서입니다. 출처: [Pleos Connect Emulator 설치 및 실행](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator), [Emulator 설정](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/configure-pleos-connect-emulator), [Virtual Console 셋업](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/use-vehicle-emulator)

## 0. 사양 확인
- 에뮬레이터에는 **외장 그래픽 카드가 필수**입니다.
  - 최소: NVIDIA GeForce RTX 3060 Laptop 6GB 이상 / AMD Radeon RX 6600M 8GB 이상
  - 권장: NVIDIA RTX 4060/5060 Laptop 8GB 이상
- RAM은 에뮬레이터에 4GB를 따로 할당합니다(PC 16GB 이상 권장).

## 1. 에뮬레이터 설치
1. [Android Studio](https://developer.android.com/studio) 최신 버전을 설치합니다.
2. Android Studio에서 **Tools → SDK Manager → SDK Update Sites** 탭 → **+** 버튼
   - Name: `Pleos Connect System Image`
   - URL (Windows): `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`
3. **SDK Platforms** 탭 → 아래 **Show Package Details** 체크 → **Android API 34**의 **Pleos Connect system Image** 체크 → OK → 설치 후 Android Studio 재시작
4. **Tools → Device Manager → Create device**
   - Form Factor: **Automotive** → **Pleos Connect v2.1.0** 선택
   - Advanced Settings: **Default boot = Cold** (Quick boot면 차량 데이터가 동작하지 않음), **RAM 4GB**, Graphics **Hardware**
   - System image: API 34 **Pleos Connect v2.1.0 APIs**
5. 만든 AVD를 실행합니다.

## 2. 앱 설치
명령 프롬프트(cmd)에서 실행합니다. `adb`는 보통 `%LOCALAPPDATA%\Android\Sdk\platform-tools`에 있습니다.

```bat
cd %LOCALAPPDATA%\Android\Sdk\platform-tools
adb install -r "C:\경로\케어로팀_케어로_release.apk"
```

에뮬레이터 앱 목록에서 **케어로**를 실행하고, 권한 요청이 뜨면 허용합니다.

## 3. Virtual Console 열기 (차량 상태 바꾸기)
```bat
adb forward tcp:8088 tcp:8088
```
브라우저에서 `http://127.0.0.1:8088/` 을 엽니다.
- **Convenience**: 조명(전조등), 와이퍼
- **Motion**: 기어, 브레이크, 주행 상태
- **Safety**: 경고등 상태
- 콘솔에 없는 값(브레이크액·엔진오일 수준, 남은 거리 등)은 앱 오른쪽 위 **데모** 버튼으로 재현합니다. 데모 값을 쓰는 동안 화면 위에 "데모 모드 · 가상 값"이 표시됩니다.

## 4. 녹화
- **Win + Alt + R** (Xbox Game Bar) 또는 [OBS Studio](https://obsproject.com/)로 에뮬레이터 창과 Virtual Console 창을 함께 녹화합니다.
- 길이 1~2분. 영상과 채널 이름에 실명이 나오지 않게 합니다.
- 유튜브에 **일부 공개**로 올리고 링크를 접수양식 7번에 적습니다.

## 5. 촬영 순서 (권장 대본)
| 순서 | 화면 조작 | 보여줄 것 |
|---|---|---|
| 1 | 앱 실행, 정차 상태 | "이번 주 내 차 컨디션" 카드 |
| 2 | 데모: 주행 중 + 남은 거리 3km + 타이어 저압 | 한 줄 안내 "도착 후 확인하세요" |
| 3 | 데모: 남은 거리 120km + 야간 | **같은 경고인데** "40km 지점 정비소에 들를까요?" + [경유지 추가] |
| 4 | [경유지 추가] 누르기 | "경유지로 추가했어요" |
| 5 | Virtual Console: 와이퍼 ON, 전조등 OFF (또는 데모: 비 + 전조등 꺼짐) | "비 올 땐 전조등을 켜주세요" |
| 6 | 데모: 브레이크액 위험 | 빨간 전체 화면 "안전한 곳에 정차하세요" |
| 7 | 데모: 주행 중 끄기(정차) | 상세 안내 카드와 권장 행동 |
